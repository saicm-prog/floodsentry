# FloodSentry — asset notes

The current cover is [`public/images/floodsentry-cover-v2.png`](../public/images/floodsentry-cover-v2.png).
It shows weather education, ZIP-code registration, readable reports, and local assistance.
The Wave Shield appears in the open top-right area without covering the four scenes or their labels.

The cover was generated and edited with the built-in OpenAI image-generation tool during AI-assisted development.
Version 1 is retained beside version 2. The generation and edit prompts are recorded in [asset-prompts/](asset-prompts/).

The app's Wave Shield source is [`public/flood-sentry-wave-shield.svg`](../public/flood-sentry-wave-shield.svg).
Email and browser icons use PNG exports of that mark. The original email attachment stays local to each email.

The weather guide uses code-based SVG illustrations in [`src/components/WeatherIllustration.tsx`](../src/components/WeatherIllustration.tsx).
The homepage also references remote Unsplash weather photographs and local image assets in `public/images/`.
Weather guidance and data sources are linked separately in the app and developer guide.
